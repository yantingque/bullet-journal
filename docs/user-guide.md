# 子彈筆記 1.0.13

這是一套給單人使用的可安裝網頁 App。手機、Windows 和桌面小視窗透過同一個私人服務讀寫資料。介面和提醒以台北時間為準。

## 在 Windows 開啟

1. 解壓縮整個資料夾。電腦需有 Node.js 24 或更新版本。
2. 雙擊 `Start-Journal.cmd`，保留啟動視窗。首次執行會自動建立資料庫和配對密碼。
3. 在 Edge 或 Chrome 開啟 [http://localhost:8776](http://localhost:8776)，輸入啟動視窗上顯示的配對密碼。
4. 在電腦按「桌面小視窗」，或雙擊 `Open-Desktop.cmd`。視窗沒有網址列，以時間和事件名稱條列顯示今天的安排。展開「本週接下來的行程」可查看本週剩餘事件。若有逾期任務，可展開「逾期未完成」，直接完成或移到明天。點事件可編輯，按「＋」可快速記錄，也可開啟完整筆記。
5. 展開小視窗的「今日待辦」，可依優先順序查看當天未完成的任務。今日焦點會排在最前面。可直接新增、完成或移到明天。
6. 展開小視窗的「未來誌」，可按月份查看尚未排定日期的計畫。點選計畫補上日期後，就能在行事曆上查看。
7. 從小視窗右上角「＋」儲存一筆捕捉後，「捕捉箱」會自動展開。可點選記錄修改分類、日期和下一步。改成任務或事件後，該筆記會離開小視窗的待整理清單。
8. 若要登入 Windows 後自動開啟，把 `Open-Desktop.cmd` 的捷徑放進目前帳戶的 Windows「啟動」資料夾。小視窗會在服務就緒後開啟。日後可從 Windows 的「啟動應用程式」設定停用。

## 從記錄到完成

在「更多 → 教學」可開啟新手導覽，逐步認識常用功能，也能直接前往對應頁面。

- 在「更多 → 會議紀錄」可貼上逐字稿、匯入錄音或直接錄音。用電腦 Chrome 錄製線上會議時，請在瀏覽器的選擇視窗選會議分頁並開啟分享分頁音訊。需要自己的聲音時可同時開啟麥克風。只有音訊會進入錄音檔。
- 用「轉成逐字稿」在服務電腦上轉錄，再用「本地 AI 整理」產生摘要、決議、待辦與待確認。逐字稿和整理結果都可以編輯，儲存後會同步。需要保留原始音檔時，關閉視窗前先下載錄音。
- 會議紀錄可以選「上課」、「會議」或「工作進度」。分類會決定摘要格式，已儲存的紀錄可重新分類。打開紀錄先看摘要預覽，再向下查看和編輯逐字稿。

### 在新電腦安裝會議音訊轉錄

服務電腦安裝 Python 3.11 後，在子彈筆記資料夾執行以下 PowerShell 指令。已有逐字稿時可直接貼上；摘要功能使用原有的 Ollama 設定。

```powershell
$meetingAsr = Join-Path $PWD 'data/meeting-asr'
python -m venv "$meetingAsr/venv"
$meetingPython = "$meetingAsr/venv/Scripts/python.exe"
& $meetingPython -m pip install faster-whisper==1.2.1
& $meetingPython -c "import sys; from faster_whisper.utils import download_model; download_model('small', output_dir=sys.argv[1])" "$meetingAsr/model"
```

如果自訂了 `JOURNAL_DATA`，請把模型安裝到對應資料目錄內的 `meeting-asr`，或以 `JOURNAL_MEETING_ASR` 指定安裝位置。下載完成後，轉錄在本機執行。

轉錄可選自動、GPU 或 CPU。自動模式對 30 秒內的錄音使用 CPU，較長的錄音在 NVIDIA CUDA 可用時優先用 GPU。畫面會顯示轉錄裝置，以及依已辨識到的音訊位置估算的進度。Windows 可在會議的 Python 環境安裝 NVIDIA 函式庫。

```powershell
& $meetingPython -m pip install nvidia-cublas-cu12 nvidia-cuda-runtime-cu12 nvidia-cudnn-cu12
```

CUDA 無法使用時會改用 CPU。需要固定使用 CPU 時，可在啟動服務前將 `JOURNAL_MEETING_DEVICE` 設成 `cpu`。

若要比較不同模型，可把模型下載到另一個資料夾，啟動服務前用 `JOURNAL_MEETING_MODEL` 指定包含 `model.bin` 的資料夾。未設定時使用原本的 `meeting-asr/model`。

- 在「語音新增」按「檢查語句」，可用本地 AI 標出疑似誤聽或不通順的文字，逐處核對並套用建議。若已進入語音預覽，可按「修改辨識文字／檢查語句」返回。

- 「日常」會顯示本週完成次數、目標和近 8 週完成率。固定排程可在「今天」或「日常」標記完成。選「每週自選時間」可設定每週次數，做完就按「記一次」。週日開始新的一週。
- 「健康」可手動新增量測，也可上傳體脂機截圖，交給電腦上的本地 AI 辨識。核對數值並填寫量測日期後才會存入紀錄。每個日期可存一筆，圖表可切換體重、BMI、體脂率、骨骼重量、水分率和肌肉率，各顯示最近 30 筆有該指標的量測。
- 可用右下角麥克風說「讀英文每週五天，運動每週四天」，確認個別目標後一起儲存。以天為單位時，同一天只算一天。

- 「未來誌」預設顯示本月日曆。點日期查看當天的事件、任務排程、截止、生日與日常，也可從選定日期新增事件。只有月份的規劃列在日曆下方。「全年總覽」可查看 12 個月的安排數量，點月份即可放大查看。

- 「捕捉箱 → 使用中 → 任務」可以篩選今天、逾期、即將開始或未排程的任務。開始日期已過且尚未到截止日的未完成任務，會繼續顯示在首頁「今日事項」、桌面小視窗的「今日待辦」和捕捉箱的「今天」篩選。只有未來截止日期的任務也會出現在「即將開始」。已完成的任務可從「全部」查看。

- 日期可用數字速輸，支援 MDD、MMDD、YYYYMMDD。省略年份時，會選今天起下一個符合的日期。時間可輸入 24 小時制的 HHMM，例如 0000 或 1300。輸入後按 Enter 或離開欄位即可帶入選擇器。

- 用「快速記錄 → 批次新增任務 → AI 拆分」預覽新專案與子任務。點開任務可修改標題、開始日期時間與截止日期時間。未提供的欄位可補填或留白，按「全部儲存」才會新增。
- 編輯器的「修飾語句」會為筆記內容產生可編輯的建議。按「套用修飾」才會替換表單文字。
- 從「提醒 → 本地 AI」查看已設定的模型名稱，按「測試 AI 連線」可檢查 Ollama 與模型。

- 打開已儲存的項目、日常或生日，按「刪除」會移到垃圾桶。移入當天算第 1 天，第 4 天台北時間 00:00 永久刪除。可在「捕捉箱 → 垃圾桶」查看到期時間並復原。服務關閉期間到期的資料會在下次啟動時清理。
- 在「今天」、「捕捉箱」或「日誌與筆記」點右下角的麥克風。說完按停止，確認自動分類、內容和日期後儲存。已設定本地 AI 時會用它分類，無法使用時會依關鍵字初步分類。也可以在辨識文字欄直接輸入後按「分類並預覽」。

- 右下角的「語音新增」可用本地 AI 將口語整理成項目、筆記與日期。一次說出多件事時，可以逐筆預覽、修改和儲存，也可展開「查看辨識原文」核對。電腦版的「快速記錄」和「批次新增任務」也支援語音輸入。辨識語言為台灣華語，瀏覽器可能會把語音送到其辨識服務。批次輸入可手動分行，或用「AI 拆分」整理清單。若瀏覽器無法辨識，可點選文字欄位後按 Windows + H。

- 在「日常」設定每天、每週指定星期或每月指定日期的多個提醒時段。當天每個時段可在「今天」完成、略過或復原。每月日期不存在時跳過該次。
- 在「日常」新增生日，填月日、提醒時間，並選當天或提前 1、3、7 天。2 月 29 日的生日出現在閏年。日常和生日通知沿用 App 的系統推播。
- 在「日誌與筆記」按日期記日誌，或建立可連到專案的獨立筆記。搜尋會比對這兩類記錄的標題和內容。
- 在「快速記錄」選「批次新增任務」，貼上一行一筆的清單，或用手機鍵盤聽寫。預覽後可一次儲存最多 50 筆，新增的任務在捕捉箱的「任務」分類。
- 本地 AI 由電腦上的 Ollama 提供。安裝 Ollama 與本機模型後，把模型名稱寫入 `data/ai-model.txt` 並重啟服務，也可在啟動時設定 `JOURNAL_AI_MODEL`。批次新增可用「AI 拆分」產生待確認的清單，日誌可用「用本地 AI 回顧」查看摘要。App 只把你選擇整理的文字送到電腦的本機 Ollama。

### 設定文字整理模型

以下用曾驗證過的文字模型示範。請在電腦啟動 Ollama，再於子彈筆記目錄執行。

```powershell
ollama pull qwen3.5:9b
New-Item -ItemType Directory -Path data -Force | Out-Null
Set-Content -Path data/ai-model.txt -Value 'qwen3.5:9b' -Encoding ascii
```

重啟子彈筆記後，到「更多 → 提醒 → 本地 AI」按「測試 AI 連線」。健康截圖辨識另外需要支援圖片輸入的模型。

### 整理任務與專案

手機快速記錄可按「儲存並繼續」連續新增。下一筆會沿用分類，日期、標題和其他欄位可重新填寫。

1. 開啟「快速記錄」，輸入標題即可存成捕捉。手機可用上方按鈕切換「捕捉」、「任務」或「事件」。選任務或事件後，可用「今天」或「明天」設定排程日期。其他分類可從「分類」選單選取。
2. 在「捕捉箱」開啟項目，補上「下一步」、優先順序和日期。只知道月份時，可獨立設定「未來誌月份」。子任務可指定一個上級專案。
3. 把今日任務設為焦點。一天可有一個焦點。完成它後，下一件事會從今天或逾期的未完成任務挑選，先比較優序，再比較日期與建立時間。
4. 在「今天」完成或移到明天。用「本週」查看週行程，用「未來誌」看各月份。完成記錄可保留，也可在編輯時封存，日後能在捕捉箱解除封存。
5. 「排程日期」用來安排哪天開始做。任務可以另外填截止日期與截止時間。到截止時間仍未完成會列為逾期，只填截止日期時，隔天才算逾期。沒有期限的任務仍依排程日期判斷逾期。未完成任務還沒排日期，或排在今天及之前時，可以按「移到明天」。若只填了截止日期，則以截止日期判斷。這個按鈕只會更改排程。事件時間是開始時間。單筆提醒依排程時間計算。
6. 在任務設定「截止提醒」，可選截止時、提前 15 分鐘、1 小時或 1 天。只填截止日期時，以當天結束為準。到「提醒」可查看提醒紀錄，或調整每日摘要、晚間未完成提醒和週日摘要。每週從週日開始，到週六結束。

在「專案」頁展開專案，即可查看子任務與完成進度。「下一個任務」依優先順序選出未完成且未封存的子任務，並顯示該筆任務填寫的「下一步」和排程。按「新增子任務」會自動帶入上級專案。桌面小視窗底部也能開啟專案頁。

展開專案的「時間軸」，可沿橫線按日期與時間查看子任務。圓點是排程，菱形是截止。節點較多時可左右捲動。「跳到今天」會定位到今天第一個節點，今天沒有節點時就定位到下一個日期，所有日期都已過時則顯示最後一個節點。點任一節點的任務即可編輯。

點「只看截止」可隱藏排程節點，再點一次即可顯示全部。開啟篩選時，「跳到今天」會在截止節點中定位。

## 配對手機和啟用背景推播

手機和電腦需要能打開同一個服務網址。兩台裝置輸入同一組配對密碼後，App 開啟時會定期同步。服務必須持續運作，才能同步與排程。

- **試用同一個 Wi-Fi 的同步**。如果該網路允許裝置互連，可在 PowerShell 設定 `$env:JOURNAL_HOST='0.0.0.0'` 後啟動，手機以電腦內網 IP 和 8776 埠開啟。HTTP 模式限受信任的開發環境和試用資料。
- **在手機安裝**。以有受信任憑證的 HTTPS 網址提供服務。Android 可從瀏覽器安裝，iPhone 從 Safari 分享選單加入主畫面。兩端使用同一個網址。
- **接收系統推播**。在本資料夾執行 `npm ci` 安裝推播依賴，重新啟動服務。開啟 App 的「提醒」→「用這台接收」，允許通知後按「測試推播」。若再指定另一台裝置，後續推播會改送到新的主要接收裝置。未設定推播時，可在「提醒紀錄」查看已產生的通知。

有現成的 HTTPS 反向代理時，設定 `JOURNAL_HTTPS=1` 並把流量轉發到服務原本的埠。直接由本服務提供 HTTPS 時，設定 `JOURNAL_CERT` 與 `JOURNAL_CERT_KEY` 為受信任憑證和私鑰路徑。可用 `JOURNAL_DATA` 指定資料目錄，`JOURNAL_PORT` 自訂埠，`JOURNAL_PUSH_SUBJECT` 指定 Web Push 聯絡信箱，例如 `mailto:you@example.com`。

持久資料預設在 `data/journal.sqlite`，需要備份時先停止服務再複製資料檔。更新時，在原本解壓縮的資料夾替換程式檔即可沿用 `data`。手機實機安裝、HTTPS 部署與背景推播到達須在實際使用的環境驗證。
